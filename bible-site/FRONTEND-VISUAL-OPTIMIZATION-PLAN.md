# Bible-Master 前台視覺優化工程規劃

本規劃以純靜態原生 HTML／CSS／JavaScript、無外部依賴、不硬編碼經文、保留既有功能為原則，優先改善無障礙、長文閱讀與可維護性。此規劃依現況摘要制定，實作前須對照原始碼及畫面確認；其中對比度數值與具體樣式均為待驗證建議。

## 一、現況盤點與優化邊界

| 維度 | 已具備項目 | 建議新增或修正 |
|---|---|---|
| 基礎架構 | 純靜態 HTML、CSS、JavaScript；無框架及外部資源；以本地 JSON 載入經文；共用導覽與樣式。 | 保留 JavaScript 綁定的 ID、data 屬性及事件邏輯，經文維持動態載入。 |
| 色彩 | 暖色背景、白色表面、深色正文與棕色強調色；CSS 變數及系統深色模式。 | 檢視次要文字、邊框、高亮與焦點色，校準深淺色對比。 |
| 排版 | 系統字體、16px 基準、1.75 行高、約 40em 內容寬度。 | 明確區分標題、節號與參照層級；節號使用等寬數字。 |
| 響應式 | 手機優先，章節卡片採網格排列。 | 統一容器內距、觸控區域與控制項對齊。 |
| 無障礙 | 基本語意標籤與樣式。 | 重新確認既有複測報告中的焦點與 CSS 選擇器問題。 |

## 二、色彩與排版規格

以下色票為建議，應依實際相鄰背景逐一量測對比；沿用或調整現有變數名稱時須檢查所有引用。

```css
:root {
  --bg-page: #f7f5ef;
  --bg-surface: #ffffff;
  --text-main: #2c2b28;
  --color-accent: #7a4a1f;
  --text-muted: #5c5952;
  --border-subtle: #e2ddd3;
  --bg-hover: #efeae0;
  --bg-highlight: #f3e5c8;
  --focus-ring: #7a4a1f;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-page: #181715;
    --bg-surface: #22211e;
    --text-main: #e6e2d8;
    --text-muted: #a39e93;
    --color-accent: #d89b60;
    --border-subtle: #36342f;
    --bg-hover: #2c2a26;
    --bg-highlight: #4a3820;
    --focus-ring: #e8b078;
  }
}
```

- 使用系統字體與繁體中文系統字體，不載入外部字體。經文是否使用系統明體可另行評估。
- 主標題建議手機 1.375rem、桌面 1.625rem，行高 1.35、字重 700；區塊標題 1.125–1.25rem，行高 1.4、字重 600。
- 經文建議手機 1rem、桌面可調至 1.0625rem，行高維持 1.75，段落間距約 0.75em，內容最大寬度約 40em。
- 節號及參照可評估 0.8125rem 和次要文字色，節號使用 `font-variant-numeric: tabular-nums`。是否排除節號選取應先確認既有複製需求。

## 三、共用導覽與頁面建議

以 CSS 或最小幅度的語意調整為原則，保留資料讀取及既有功能。

### 共用導覽

- 以顏色以外的方式明確標示目前頁面，例如加粗及底線。
- 確保導覽項目有充足觸控區域，手機版可換行而不截斷文字。

### 目錄

- 清楚區分已選取和未選取的書卷，並保留鍵盤焦點提示。
- 依卡片實際內容調整網格欄寬；章節卡片建議至少 48 × 48px，數字對齊，並提供互動回饋。
- 搜尋欄與按鈕高度至少 44px；確認輸入框邊界和焦點清楚可辨。

### 逐章閱讀

- 逐節排列時，可使用 Grid 或 Flex 將節號與經文分欄，讓多行經文左緣對齊。
- 參照資訊採較低視覺層級；可點擊的連結保持可辨識。
- 上下章導覽提供足夠大的點擊區域，建議高度至少 48px，並處理首末章狀態。

### 經文搜尋

- 統一輸入框與按鈕尺寸，手機版視空間採單列或堆疊。
- 明確呈現結果數量與無結果提示。
- 強化經文出處層級；若已有關鍵字高亮，確認深淺色下的文字與背景對比。

### 經文卡片

- 書卷、章、節控制項採適合手機的排列，選單高度至少 44px。
- 預覽依容器寬度等比例縮放，避免水平溢出，並以邊框或微陰影區分背景。
- 保持 Canvas 實際像素尺寸及繪圖邏輯，透過 CSS 控制顯示尺寸，驗證下載圖片的解析度與排版。

## 四、響應式配置

- **手機預設**：左右內距約 1rem；導覽可單列或換行；卡片控制項與預覽上下排列；主要觸控目標至少 44 × 44px。
- **平板及桌面**：於適當斷點增加內距至約 2rem，主要內容維持約 40em 並置中；章節網格依空間增加欄數。卡片頁可維持單欄，或評估寬螢幕雙欄。
- 優先沿用現有斷點，依實際畫面需要調整，避免不必要的斷點。

## 五、無障礙與 CSS 修復

1. 盤點實際 HTML 與 JavaScript 動態產生的 DOM，確認選擇器、權重及瀏覽器解析結果；重新檢查既有報告，不預設問題仍存在。
2. 修復失效規則，為連結、按鈕、輸入框、選單與其他可聚焦元件提供清楚的鍵盤焦點，避免無條件移除外框。例如：

```css
a:focus-visible,
button:focus-visible,
input:focus-visible,
select:focus-visible,
[tabindex]:focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
}
```

3. 檢查既有測試對 `:focus` 與 `:focus-visible` 的要求及相容性。
4. 在實際背景上量測文字、互動元件邊界及焦點對比；一般文字以至少 4.5:1 為驗收目標。
5. 保留搜尋及各選單的可存取名稱，確保標籤與控制項正確關聯。

## 六、分階段執行

### P0：盤點與無障礙／CSS 修復

- 閱讀共用樣式、四個 HTML 頁面、JavaScript 渲染邏輯與既有檢查腳本。
- 確認並修復選擇器與焦點問題。
- 檢查深淺色變數及對比，補足必要的語意色。

### P1：核心閱讀與查找

- 改善經文、節號、參照與上下章導覽的間距與對齊。
- 改善書卷切換、章節卡片觸控區域及搜尋結果視覺層級。

### P2：經文卡片及跨裝置細節

- 調整控制項與預覽的響應式排列，驗證圖片下載。
- 檢查共用導覽、頁尾與四個頁面的留白一致性。

## 七、驗收清單

每個階段完成後執行專案既有檢查。從專案根目錄執行：

```bash
python3 bible-site/tools/check_all.py
```

- [ ] 自動化檢查結束碼為 0，並檢查報告中的失敗與回歸。
- [ ] 四個頁面可依合理順序使用 Tab／Shift+Tab 操作，焦點清楚可見。
- [ ] 測量深淺色模式下正文、次要文字、連結、按鈕及焦點的實際對比。
- [ ] 檢查手機版主要互動控制的觸控尺寸與間距。
- [ ] 於 320、375、768、1440px 寬度檢查四個頁面，無非預期水平捲動或文字截斷。
- [ ] 驗證書卷切換、章節載入、搜尋結果與空狀態。
- [ ] 驗證卡片書卷／章／節切換、預覽及完整圖片下載。
- [ ] 確認經文仍僅由本地 JSON 載入，沒有引入外部資源。
