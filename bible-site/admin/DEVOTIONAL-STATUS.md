# 每日禱讀上架狀態看板

啟動本機後台後，往下找到「每日禱讀上架狀態」。新版可於 http://127.0.0.1:8093/ 使用；內容新增、修改、審核與上架操作見 [內容管理說明](DEVOTIONAL-EDITOR.md)。既有後台服務保留。

看板首次載入會查詢一次；「重新整理」只更新此卡片，查詢期間暫停重複操作。這是唯讀看板，不會核准內容、修改排程或執行發布。

| 區塊 | 資料來源與用途 |
| --- | --- |
| 正式站公開 | 固定正式站的`data/devotional.json`，顯示公開篇數與最新日期 |
| 本機匯出 | 此後台所使用的本機`data/devotional.json`，另列篇數及日期；可能落後於每日發布checkout |
| 發佈排程 | 目前使用者systemd實際載入的禱讀timer，顯示啟用、運作、下一次與可確定的截止日 |
| 最後執行 | 禱讀發布service的起訖時間、結果與退出碼 |

「已排程」代表有可核實的有效排程，不代表未來內容已公開。台灣日期超過已載入的截止日，顯示「已依設定截止」。缺少來源時顯示未知或無法取得；另一來源仍可正常顯示。空陣列會顯示0篇，與無法取得不同。

若整體查詢失敗或超過12秒，看板清除先前成功數字，顯示「資料未更新」，可再次重新整理。正式站或systemd個別失敗會留在對應區塊，不會冒充零篇或發布成功。核對觀測時間與資料來源後，再判斷是否需要處理。

目前使用者設定已於2026-11-16延長為2026-12-16含當日截止；看板從實際設定判定日期，沒有把此日期寫死在介面。多條可辨識的有限月份規則取最後截止日；若含無限或未知規則則顯示未知，不自行猜測。8093 新版服務已載入跨月份辨識；仍使用舊 8092 長駐服務者請切換至新版入口。
