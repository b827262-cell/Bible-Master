# 每日禱讀內容管理

本機後台入口：<http://127.0.0.1:8093/#devotional-editor>。在執行專案的主機瀏覽，無須開啟公開網站的管理頁。

## 日常操作

1. 在「每日上架設定」調整啟用、開始日期、截止日期（含當日）、每日執行時間，按「儲存設定」。時區固定為台灣；目前維持 2026-11-16 至 2026-12-16、每日 06:00。
2. 在日期範圍內找文章按「編輯」。新增日期則按「新增內容」；已有文章的日期請編輯原文，避免撞期。
3. 填寫日期、主題、經文出處、默想、反思與禱告。來源網址可留空，儲存時採用本站經文頁。按「預覽經文」核對唯讀經文，再按「儲存草稿」。
4. 儲存草稿後，填寫審核者姓名，逐項核對並勾選來源／經文及默想／反思／禱告兩項確認，再按「確認審核並排入上架」。修改欄位後需重新儲存與確認。
5. 核准後等待逐日排程，或在有效上架期間按「立即上架已核准內容」。只公開台灣當天及以前的已核准文章，未來文章等到對應日期才公開；文章日期若超出目前排程期間，須先調整上架設定。

草稿只存在資料庫，原已核准文章保留到修訂再次核准。儲存、核准與正式網站更新是不同階段，正式公開結果請看上方「每日禱讀上架狀態」。遇到版本衝突時，輸入會保留；先自行保留修改內容，再重新讀取最新版本。未儲存輸入不會跨頁保存在瀏覽器。

暫停自動排程只影響之後的自動上架；有效期間仍可手動上架。手動上架完成代表上架服務完成，正式網站仍需等待更新並重新整理確認。若等待逾時，先重新讀取狀態，服務可能仍在執行。

## 管理員維護

新版以使用者服務 `bible-site-admin-editor.service` 在 127.0.0.1:8093 運行，已啟用自動啟動；既有 8091（adapter）與 8092 服務保留。服務範本見 `systemd/bible-site-admin-editor.service`，權杖獨立存放於 `~/.local/state/bible-master/admin-editor/token`，不覆寫舊後台權杖。程式更新後重啟此服務才會載入新版 Python；重啟前先儲存後台表單。

新增資料庫 migration 為 `../devotional/005_admin_editor.sql`，需先完成既有 schema/grants/002/003/004。此 migration 不可重複套用；只新增草稿表、索引與固定函式，不修改既有文章／經文／審核紀錄。沒有自動 migration 的 HTTP 端點。

排程管理只擁有 timer/service 下的 `zz-admin-release.conf`，既有 host 與截止範本保留。每次變更前會在 `~/.local/state/bible-master/devotional-admin/` 建立私人備份，失敗會嘗試還原並查驗。非本程式的同名檔案、自訂未知條件與符號連結會拒絕覆寫。

驗收：`python3 -B bible-site/tests/devotional_editor_checks.py` 使用唯一命名隔離 PostgreSQL 資料庫，結束時只刪除本次建立的測試庫；需能以既有 SSH 連至 postgres。`python3 -B bible-site/tests/devotional_operations_checks.py` 使用模擬服務與暫存設定，不修改真實排程。完整結果見 `../REVIEW-devotional-admin-editor.md`。
