# 任務 4/5：搜尋頁

請建立 `bible-site/site/search.html`（只這一個檔案）。引用已存在的 `style.css` 和 `app.js`（先讀 app.js，不要改它）。

行為：
- 一個搜尋框與送出鈕；網址 `search.html?q=關鍵字` 要直接帶入並自動搜尋（不需再按鈕）。
- 用 `Bible.load()` 讀資料，在全部 16 章每節的經文中找出包含關鍵字的節（單純子字串比對）。
- **每一個符合的節都要列出，不可截斷或分頁**，格式：「馬可福音 章:節」（用 `Bible.ref`）+ 經文，且每筆的「馬可福音 章:節」是連到 `chapter.html?ch=章#v節` 的連結。經文中的關鍵字用 `<mark>` 標出（注意要先跳脫再標示）。
- 顯示「共 N 筆」。沒有關鍵字時顯示提示；沒有結果時顯示「找不到符合的經文」。
- 驗收：搜尋「耶穌」必須顯示 274 筆。

## 共同規則（務必遵守）
- 工作區是 Bible-Master，網站檔案放在 `bible-site/site/`。
- 經文只能用 fetch 從 `../data/mark.json` 讀取。格式：`{book, version, chapters:[{ch, verses:[{v, text}], notes:[...]}]}`。程式裡不准寫任何經文。
- 不載入任何外部資源（不用 CDN、外部字型、外部圖片），字型用系統字型。
- 介面文字全部用繁體中文，要能在手機（375px 寬不橫向捲動）和桌面使用。
- 這個任務只寫下面列出的檔案，不要動其他檔案，也不要一次寫更多檔案。
- 寫完後執行 `python3 bible-site/tools/check_all.py`，只回報最後一行總結和你改了哪些檔案。尚未建立的其他頁面造成的失敗是正常的，不用處理。
