### 焦點外框 — **不通過（修正未生效，且造成回歸）**

`style.css` 第 306 行內容是：

```
306: .nav-list a:focus-visible,.chapter-card:focus-visible,.book-tabs a:focus-visible {
  outline: 2px solid var(--focus);
  outline-offset: 2px;
}
```

行號 `306:` 被誤貼進 CSS 選擇器，**整條規則被瀏覽器判定為非法並丟棄**。證據（三重驗證）：

1. **CSSOM 實測**：`document.styleSheets` 中 `style.css` 只有 **45 條**規則，`focus-visible` 相關規則 **0 條**。
2. **computed style 實測**（淺色／深色皆同）：
   | 元素 | 預期（規則生效時） | 實測 |
   |---|---|---|
   | `#nav a`（導覽列連結） | `solid 2px rgb(179,84,0)` offset 2px | **`auto 1px rgb(16,16,16)`** offset 1px |
   | `.book-tabs a`（書卷標籤，本輪新增目標） | `solid 2px rgb(179,84,0)` offset 2px | **`auto 1px rgb(16,16,16)`** offset 1px |
   | `.chapter-card`（章節卡片） | `solid 2px rgb(179,84,0)` offset 2px | **`auto 1px rgb(16,16,16)`** offset 1px |
   | 對照：`input`（不受此規則影響） | `solid 2px` | `solid 2px rgb(179,84,0)` ✓ |
   | 對照：`button` | `solid 2px` | `solid 2px rgb(179,84,0)` ✓ |
3. **像素比對**：三類元素的焦點外框仍是瀏覽器預設色，不是設計的 `--focus` 橘色。

**影響評估（實話）**：焦點**仍看得見**——瀏覽器預設 `auto` 外框在淺色下是黑框（對比 17.45–19.03:1）、深色下是白框（18.08:1），都遠高於 3:1 門檻。所以**沒有造成「鍵盤使用者看不到焦點」的無障礙災難**；但：
- 上一輪已修好的「2px 橘色統一焦點外框」**確實回歸失效**（原本 nav／chapter-card 是 `solid 2px var(--focus)`，現在退回預設 `auto 1px`）。
- 本輪新增的 `.book-tabs a:focus-visible` **完全沒有作用**，等於白做。
- 預設 `auto` 外框顏色由瀏覽器決定，跨瀏覽器／深色模式下不一致，比不上設計指定的 `--focus` 色。

**建議修法（給 PM，非 tester 改）**：把第 306 行開頭的 `306: ` 刪掉，改成：
```css
.nav-list a:focus-visible,
.chapter-card:focus-visible,
.book-tabs a:focus-visible {
  outline: 2px solid var(--focus);
  outline-offset: 2px;
}
```
修完後建議用 `python3 -c` 或瀏覽器 Console 確認 `document.styleSheets` 內含 3 個選擇器的 `:focus-visible` 規則（本報告 E8 的檢查方式可直接複用）。

## 不通過詳情

### E6／E8 焦點外框修正未生效（CSS 選擇器含行號）

- **網址**：全部頁面（`index.html`、`chapter.html`、`search.html`、`card.html`）
- **檔案**：`bible-site/site/style.css` 第 306 行
- **實際內容**：
  ```
  306: .nav-list a:focus-visible,.chapter-card:focus-visible,.book-tabs a:focus-visible {
  ```
  正確應為（刪掉開頭 `306: `）：
  ```
  .nav-list a:focus-visible,.chapter-card:focus-visible,.book-tabs a:focus-visible {
  ```
- **步驟**：開頁 → 讀 `document.styleSheets` 規則數 → Tab 走訪元素讀 `getComputedStyle().outline`
- **實際結果**：
  - `style.css` CSSOM 只有 45 條規則，`focus-visible` 相關 **0 條**
  - `#nav a`、`.book-tabs a`、`.chapter-card` 的 computed outline 是 `auto 1px rgb(16,16,16)`（瀏覽器預設），**不是**預期的 `solid 2px rgb(179,84,0)` offset 2px
  - 對照組 `input`／`button` 仍是 `solid 2px`（因為它們的規則是另一段、語法正確），證明不是量測問題
- **判定理由**：本輪聲稱新增的 `.book-tabs a:focus-visible` **完全沒有作用**；且上一輪已修好的 nav／chapter-card 2px 橘色外框**回歸失效**。
- **影響**：焦點仍可見（瀏覽器預設外框在淺色 17.45–19.03:1、深色 18.08:1），**沒有造成鍵盤使用者看不到焦點**；但設計樣式不一致、跨瀏覽器表現不可控，且新增的書卷標籤焦點樣式等於白做。
- **建議**：刪掉第 306 行開頭的 `306: `。修完可執行本報告 E8 的檢查：確認 `style.css` CSSOM 含 `focus-visible` 規則、且三類元素 computed outline 為 `solid 2px rgb(179,84,0)`（深色為 `rgb(224,164,92)`）。
