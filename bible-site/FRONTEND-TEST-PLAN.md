1. **Front-end Engineer**（Harness，Bible-Master 工作區）：照 A–E 測試，寫 `bible-site/FRONTEND-TEST-REPORT.md`，每案標「通過／不通過」，不通過要附網址、步驟、實際結果（有截圖更好）。不改 `site/`。
2. **PM（我）**：用腳本複驗報告中的不通過項目與期望值，把確定的問題寫進 `FAILS.md` 格式交 E500。
3. **E500**：一次只修一個檔案；修完 PM 跑 `check_all.py` 與相關案例。
4. **De1050**：最後跑一次 `check_all.py` 回報最後一行。
5. 最多 3 輪；還修不好的寫 `TODO.md` 交貓聽。
